## 📖 项目简介

Storybook 是一个面向前端的工作台(workshop),让开发者可以隔离地构建、展示 UI 组件和页面。成千上万的团队用它来完成 UI 开发、组件测试和文档编写,它也因此成为 UI 组件工程化领域事实上的行业标准。借助丰富的插件生态,Storybook 还能覆盖组件设计、交互测试、视觉回归、可访问性检查等场景,并已扩展支持 React Native、Android、iOS 和 Flutter 等移动端开发。

## ✨ 主要特性

- 🛠 **隔离开发**:脱离业务上下文,单独构建和调试每个组件、每种状态
- 📒 **多框架支持**:React、Vue 3、Angular、Svelte、Web Components、Preact、HTML、Ember、Qwik、SolidJS,以及 React Native / Android / iOS / Flutter
- 📝 **文档生成**:为组件自动生成高质量使用文档,让组件库自带说明书
- 🧪 **测试友好**:配合 test-runner、jest 等工具做交互测试、单元测试与视觉回归
- ♿ **可访问性检查**:内置 a11y 插件,提前发现无障碍问题
- 🔗 **丰富插件生态**:actions、backgrounds、viewport、measure、outline、links、graphql 等大量官方与社区插件
- 🎨 **响应式调试**:随时切换视口尺寸和布局,验证响应式组件表现
- 👥 **活跃社区**:官方 Discord、GitHub Discussions、博客与 YouTube 教程
- 🏅 **展示物料**:提供官方徽章(Badge)与品牌素材,方便在 README 和演讲中展示

## 🚀 快速开始

1. 进入你的前端项目目录(支持 React / Vue / Angular / Svelte 等):

```bash
cd my-frontend-project
```

2. 一条命令初始化 Storybook(自动检测框架并安装依赖):

```bash
npx storybook@latest init
```

3. 启动开发工作台(初始化完成后通常已自动启动):

```bash
npm run storybook
```

4. 浏览器打开提示的本地地址(默认 http://localhost:6006),即可在隔离环境中查看、调试组件。

5. 构建静态文档站(可部署到任意静态托管):

```bash
npm run build-storybook
```

6. 想先看效果?访问 [storybook.new](https://storybook.new) 可在 StackBlitz 中秒开一个示例项目;也可以到 [Component Encyclopedia](https://storybook.js.org/showcase?ref=readme) 参考顶尖团队的真实用法。

7. 遇到问题?欢迎到原仓库的 [GitHub Discussions](https://github.com/storybookjs/storybook/discussions/new?category=help) 提问。
