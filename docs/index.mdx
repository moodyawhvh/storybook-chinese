Storybook 是一个前端工作台（workshop），用于以隔离方式构建 UI 组件和页面。它帮助你开发和分享难以触达的状态与边界情况，而无需运行整个应用。成千上万的团队用它进行 UI 开发、测试和文档编写。它是开源且免费的。
